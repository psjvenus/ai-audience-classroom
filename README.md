# AI 예상 청중과 함께하는 발표 내용 생성·조직

중학교 2학년 국어 '청중을 고려하여 발표하기' 연구수업용 웹 프로그램 MVP입니다. **모둠당 안드로이드 태블릿 1대**에서 학생들이 로그인 없이 공동 작성하며, 교사는 모둠별 활동지를 확인합니다.

## 구현 기능

- 학생: 참여 코드 + 모둠 번호 + 6자리 모둠 비밀번호로 입장 (계정 없음)
- PPT 활동지 5단계: 발표 계획 / 청중 특성 분석 / 청중 특성 반영 / 자료 조사·재구성 / 발표 내용 조직
- OpenAI API를 사용하는 가상 예상 청중 채팅 (서버 측 호출)
- 약 1초 입력 중단 후 자동 저장, 재접속 시 복원
- 교사: 비밀번호 로그인, 수업 생성, 모둠 비밀번호 확인, 약 4초 간격 활동지·대화 확인
- 전체 화면 전환 요청, 화면 숨김 횟수 참고 기록, 인쇄

## 로컬 설치

1. Node.js 20 이상 설치
2. 이 폴더에서 `npm install`
3. Supabase 프로젝트 생성 → SQL Editor에서 `supabase.sql` 실행
4. `.env.example`을 `.env.local`로 복사하고 환경 변수 입력
5. `npm run dev` → `http://localhost:3000` 접속
6. `/teacher`에서 교사 로그인 → 수업 생성 → 참여 코드 및 모둠 비밀번호 안내
7. 태블릿에서 `/student` 접속 → 모둠 입장

**중요:** `SUPABASE_SERVICE_ROLE_KEY`, `OPENAI_API_KEY`, `SESSION_SECRET`, `TEACHER_PASSWORD`는 서버 환경 변수에만 넣고 GitHub에 올리지 마세요. `.env.local`은 `.gitignore`에 포함되어 있습니다.

## Vercel 배포

1. GitHub 새 저장소에 이 폴더 업로드
2. Vercel에서 해당 저장소 Import
3. Environment Variables에 `.env.local`의 값 입력
4. Deploy → `https://...vercel.app/student` 학생 주소 안내
5. `https://...vercel.app/teacher` 교사 주소 접속

## 학교 태블릿 수업 집중 모드

웹 전체 화면 API는 일부 Android 브라우저에서 지원되지 않으며 홈 버튼, 앱 전환을 차단하지 못합니다. 화면 숨김 기록은 오탐/누락이 있어 학생 통제나 평가 근거로 사용하면 안 됩니다. 실제 앱 제한이 필요하면 학교 관리자와 삼성 Knox/Android Enterprise 키오스크 설정을 검토하세요.

## 운영 전 보완 필수 (MVP 제한)

- 교사 인증은 **배포 단위 공통 비밀번호**이며 다중 교사 계정·권한 분리가 없습니다.
- 모둠 PIN 시도에 대한 **서버 측 속도 제한/잠금**을 추가해야 공용 인터넷에서 안전하게 운영할 수 있습니다.
- 동시 입력 충돌 제어 없음 (모둠당 1대 사용 전제).
- 대화 메시지 동시 전송 시 덮어쓰기 가능, 대화 길이는 최근 16개 메시지로 제한됨.
- 교사용 새로고침은 4초 간격 폴링으로 엄밀한 실시간 구독이 아닙니다.
- 데이터 보존 기간/삭제 기능, 제출 완료 잠금, 다운로드 파일 기능은 후속 버전에서 추가 예정입니다.
- 학생 개인 정보, 실명, 민감 정보를 입력하지 않도록 안내하고 학교 개인정보 처리 방침 및 외부 AI 사용 승인 여부를 확인하세요.
- 서비스 사용 전 학교 와이파이에서 Vercel, Supabase, OpenAI API 연결을 시험하세요.

## 교육적 원칙

AI는 가상의 청중 역할로만 답하며 학생 대신 발표문을 완성하지 않도록 지시합니다. AI 응답은 사실 자료가 아니므로 실제 자료 조사와 출처 확인이 필요합니다.

## 2단계 예상 청중 챗봇 연결 (선택 설정)

Vercel → 프로젝트 → Settings → Environment Variables에 다음 값을 추가합니다.

- Key: `NEXT_PUBLIC_AUDIENCE_GPT_URL`
- Value: 공개 공유 설정한 실제 맞춤형 GPT 주소 (`https://chatgpt.com/g/...`)

변수 저장 후 Vercel에 다시 배포해야 새 값이 사이트에 반영됩니다.
변수가 설정되지 않으면 2단계에 설정 안내가 표시되며 잘못된 링크를 열지 않습니다.
학생용 앱은 여전히 로그인 없이 참여할 수 있고, 외부 ChatGPT 시뮬레이터는 별도의 로그인이 필요할 수 있습니다.
2단계에서는 로그인 안내 → 새 탭에서 챗봇 열기 → 앱으로 돌아와 청중 특성 요약 순서로 활동합니다.
공유 대화 주소 (`https://chatgpt.com/s/...`)가 아닌, **맞춤형 GPT 공유 URL**을 사용해야 합니다.
학교에서 허용한 계정과 연령·개인정보 관련 규정을 수업 전에 확인하세요.
